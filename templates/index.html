How it works

  1. You enter a URL.
  2. The system extracts lexical features (length, dots, hyphens, IP host, port, keywords...).
  3. A Random Forest model analyses those features.
  4. The probability becomes a class: Legitimate, Suspicious or Phishing.
  5. The page shows the result with the indicators behind it.

About the project

Phishing tricks people into entering passwords or payment details on fake sites. Detecting it early protects accounts and money. Machine learning learns patterns from many labelled URLs, such as odd lengths, raw IP hosts and bait words, and applies them to new links.

Technologies: HTML, CSS, JavaScript, Chart.js, Python, Flask, scikit-learn, pandas, NumPy.

Limitations: only the URL text is analysed, so false positives and false negatives happen. No single indicator proves a site is malicious. Quality depends on the training dataset.
